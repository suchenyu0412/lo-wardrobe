📥 导入

选择本应用导出的 .xlsx 表格（「数据添加」：在 Excel / WPS 里直接插图后导入），或 .zip（整包迁移，连图片一起还原）。

📷 在 xlsx 里插图（关键）：打开导出的表格，找到每件单品所在行的图片列（衣柜＝「首图」，想买＝「尺码表 / 面料表 / 人台图 / 参考图」），点「插入 → 图片」把图放进去。
⚠️ 对齐规则（锚点最上行归位）：让图片的上边缘与该行上边缘对齐即可。导入时系统按「图片顶部所在行」自动把图归位到对应单品，无需手动填路径。

📤 导出

将导出 0 件

XLSX：用 Excel / WPS 打开，可在对应行的图片列里直接插入图片（让图片上边缘与该行对齐即可），改完再导入回来，图片自动按锚点最上行归位。
ZIP：把数据与图片整包导出，换设备后导入即可完整还原，适合备份 / 迁移。

添加单品

选文件后图片会存进浏览器本地图片库（IndexedDB），按「名字-类型」一一对应；导出 ZIP 时自动带上，换设备导入即可还原。也可直接填图片链接/路径。

填了「尾款」金额和日期、但不勾「已支付」，它就会进「待付尾款」提醒并可写入日历；真正付清后再勾上「已支付」即可。

➕ 添加付款记录

店家常只说“8 月下旬开尾款”这类模糊时间，选这个就行；结束时间仍是精确日期。
