# Lo 娘衣柜 · 网页版（公开演示）

一个**纯前端**的 Lolita（Lo 娘）衣柜 / 想买清单管理工具。手机与桌面自适应，数据全部存在浏览器 `localStorage`，**无需后端、无需联网**。

## 🔒 隐私说明（重要）

本仓库是**公开演示版**：

- 内置数据为**完全虚构的示例**（虚构品牌名、示例价格、空订单号），**不含任何真实品牌、真实订单号、真实价格或个人照片**。
- 原项目中含真实衣柜数据与一套「本地订单图片爬虫」工具（需要本地 Chrome 登录态与专属服务），**未纳入本仓库**，因此不会上传任何私人信息。

## ✨ 功能

- **衣柜（已拥有）/ 想买清单** 双视图，左侧按品类竖排分类（裙子 / 内搭 / 外搭 / 头饰 / 耳饰 / 袜类 / 鞋子 …）
- 单品详情：颜色、尺码、付款明细（定金 / 尾款 / 全款 / 现货 / 运费），可**精确到「哪天几点」**，自动拆分「预约价（定金+尾款=全款）」与「现货价」
- 添加 / 编辑 / 删除单品，心愿单可拖拽调整优先级
- **定金尾款提醒**：一键导出 `.ics` 日历文件（含提前 3 天 + 当天提醒），手机点开即写入系统日历，不怕错过尾款 / 开售
- **导入 / 导出**：支持 **XLSX（批量新增）** 与 **ZIP（完整迁移）** 两种格式，换设备 / 换浏览器数据不丢
- 完全离线运行，数据保存在本机浏览器

## 📌 更新记录

### v2（最新）
- **导入 / 导出功能**
  - **XLSX（批量新增）**：在 Excel / WPS 里直接插入图片后导入，系统按「图片上边缘所在行」自动归位到对应单品，可一次性批量新增衣柜与想买清单数据。
  - **ZIP（完全迁移）**：导出含 `data.json` 与全部图片的整包，换设备 / 换浏览器后导入即可完整还原，数据零丢失。
  - 导入时已存在同名同状态单品会自动**合并图片**，重复导入不丢图。

### v1
- **定金 / 尾款精细设置**：每笔定金、尾款、现货可单独设定「哪天几点」（抢付 / 开付时间点），不再只能填日期。
- **导出到手机日历**：一键生成 `.ics` 日历文件（含提前 3 天 + 当天提醒），手机点开即可写入系统日历，再也不怕错过尾款 / 开售。

## 🚀 本地运行

直接双击打开 `index.html`（建议 Chrome / Edge）。或用任意静态服务器：

```bash
python -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000
```

## 🌐 部署到 GitHub Pages

1. 把本文件夹内容推送到你的 GitHub 仓库
2. 仓库 **Settings → Pages → Source** 选择 `main` 分支、根目录（`/root`）
3. 稍等一两分钟即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

## 📝 用自己的数据

克隆本仓库后，直接打开网页添加单品即可；或把 `index.html` 里的 `seed()` 函数替换为你自己的数据数组（字段结构见示例）。
